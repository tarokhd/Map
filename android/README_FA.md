# Iran Navigator Android

اپلیکیشن Native اندروید با Kotlin و MapLibre Native.

## امکانات نسخه فعلی
- نقشه برداری با پوسته روشن و تاریک OpenFreeMap
- ساختمان‌های سه‌بعدی در صورت وجود داده ارتفاع
- دریافت به‌روزرسانی موقعیت از GPS و Network Location
- نمایش محدوده دقت گزارش‌شده دستگاه
- انتخاب مبدأ و مقصد با لمس نقشه یا جست‌وجوی Photon
- حالت‌های خودرو، موتورسیکلت و پیاده‌روی با Valhalla
- ترسیم هندسه مسیر و نمایش دستورهای گردش
- دستورهای متنی فارسی و راهنمای صوتی Android TextToSpeech در صورت پشتیبانی دستگاه
- دنبال‌کردن زنده دوربین و تلاش برای محاسبه مجدد مسیر هنگام انحراف

## ساخت محلی
نیازمندی‌ها: JDK 17، Android SDK Platform 35 و Gradle 8.9.

از ریشه مخزن:

```bash
cd android
gradle --no-daemon :app:assembleDebug
```

خروجی:
`android/app/build/outputs/apk/debug/app-debug.apk`

## نکات
- مسیریابی عمومی Valhalla برای نمونه اولیه است.
- کیفیت پروفایل موتورسیکلت به داده‌های دسترسی OpenStreetMap وابسته است.
- صدای فارسی به نصب بودن موتور TTS و صدای فارسی روی گوشی وابسته است.
- GPS به دستگاه، محیط و دید آسمان وابسته است.
- مسیریابی پس‌زمینه، ترافیک زنده و نقشه آفلاین هنوز پیاده‌سازی نشده‌اند.
