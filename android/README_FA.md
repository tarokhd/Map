# Iran Navigator Android — World

اندروید پوسته Kotlin با GPS و مجوزهای بومی دارد. رابط و رندر سه‌بعدی از همان کد `web/` داخل APK بسته‌بندی می‌شوند؛ برنامه سایت منتشرشده را باز نمی‌کند. MapLibre GL JS و افزونه فارسی همراه با مجوزهایشان و بررسی SHA-512 داخل APK قرار دارند.

صفحه شروع فقط مقصد را می‌پرسد. پس از انتخاب مقصد، حالت خودرو/موتور/پیاده، مبدأ، مسیرهای جایگزین و ظاهر نمایش داده می‌شوند. قطب‌نمای N، خیابان‌ها و کوچه‌های تفکیک‌شده، پل‌های حجمی، پیش‌نمایش مسیر و دوربین زودهنگام خروجی در تمام نسخه‌های World مشترک‌اند.

## ساخت

نیازمندی‌ها: Python 3، JDK 17، Gradle 8.9، Android SDK Platform 35 و Build Tools 35.0.0.

```sh
node --test web/tests/*.test.mjs scripts/android_bridge.test.cjs
cd android
gradle --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`.
کلید debug به‌صورت محلی در `.gradle/debug.keystore` ساخته می‌شود و وارد Git نمی‌شود. کلیدهای debug روی ماشین‌های متفاوت یکسان نیستند؛ برای نصب روی نسخه‌ای با امضای متفاوت، ابتدا نسخه قبلی را حذف کنید.

حداقل Android 7 با Android System WebView به‌روز و WebGL2 لازم است. GPS تنها بعد از درخواست کاربر و مجوز سیستم فعال می‌شود و در پس‌زمینه متوقف می‌شود. دکمه برگشت ابتدا پنل جست‌وجو یا ناوبری را می‌بندد.

## محدوده تست

APK از نوع debug است. داده نقشه، جست‌وجو و مسیریابی آنلاین‌اند؛ ظاهر و موتور نمایش داخل APK هستند. ارتفاع پل‌ها و خط‌کشی‌ها شماتیک‌اند، نه اندازه‌گیری مهندسی یا راهنمای لاین. داده ناقص نقشه می‌تواند پل یا کوچه‌ای را نشان ندهد. ترافیک زنده، نقشه آفلاین، ناوبری پس‌زمینه و تست روی گوشی واقعی هنوز جزو تأیید این خروجی نیستند.
