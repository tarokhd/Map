# Iran Navigator Android Demo

نسخه آزمایشی اندروید Iran Navigator با Kotlin و MapLibre Native.

## قابلیت‌ها
- نمایش نقشه تهران با استایل برداری
- دوربین مایل و تغییر زاویه 2D/3D
- نمایش ساختمان‌های سه‌بعدی در صورت وجود داده ارتفاع
- انتخاب دو نقطه با لمس نقشه و نمایش خط مسیر نمونه
- جست‌وجوی مکان با Photon
- درخواست موقعیت دستگاه با اجازه کاربر

## ساخت APK
پروژه با JDK 17، Android SDK Platform 35 و Gradle 8.9 ساخته می‌شود.

در Android Studio پوشه ریشه‌ای را باز کنید که فایل‌های `settings.gradle.kts` و `build.gradle.kts` در آن قرار دارند.

برای ساخت نسخه آزمایشی:
```bash
gradle --no-daemon :app:assembleDebug
```

خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## محدودیت‌ها
این نسخه صرفاً نمونه اولیه است. خط مسیر با دو نقطه انتخابی رسم می‌شود و موتور مسیریابی اختصاصی ایران یا ترافیک زنده ندارد. سرویس‌های عمومی نقشه و جست‌وجو برای آزمایش هستند و برای استفاده پرترافیک تولیدی مناسب فرض نمی‌شوند.
